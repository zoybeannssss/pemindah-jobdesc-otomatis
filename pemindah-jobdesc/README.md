# Program Pemindah Job Desc 4.0

Project ini digunakan untuk melakukan ekstraksi otomatis komponen **Tugas Pokok Spesifik** dari template Job Desc lama ke template Job Desc baru.

## Cara Penggunaan di GitHub Codespaces / Local Python:

1. Extract file zip ini.
2. Buka terminal di folder project ini.
3. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan script utama:
   ```bash
   python main.py
   ```
5. Hasil migrasi akan tersimpan secara otomatis di `files/Hasil_Migrasi_JobDesc.xlsx`.
